# 02 — Sala viva: chat persistente y presencia

**What to build:** La sala compartida sobre la que los tres van a probar todo lo demás. Entras desde un enlace, escribes, ves lo que escriben los otros, y ves quién está. Sin grafo todavía.

Es también el primer despliegue: a partir de aquí nadie prueba en localhost.

**Blocked by:** Ninguno — se puede empezar de inmediato.

**Status:** done

- [x] Se entra a la sala desde un enlace, sin crear cuenta
- [x] Un mensaje escrito en una pestaña aparece en el hilo de las otras dos
- [x] Quien abre una cuarta pestaña a mitad de conversación ve el historial completo del chat
- [x] El roster muestra quién está en la sala y se actualiza al entrar y al salir
- [x] Cada mensaje muestra quién lo escribió
- [x] Corre en el entorno desplegado y no en una laptop; el primer mensaje de una sesión no espera a un cold start
